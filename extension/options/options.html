An API key is just a password this extension uses to prove it's you. You create it in your own Sincerely account — it isn't something you get from anywhere else. On the Webhooks page, API keys tab, press Create Key, then use the copy button beside the key (selecting the text copies the dots that hide it, which won't work).

How it works

Three actions that are easy to confuse.

Add
Puts someone on a lead list. The contact is created first if your account has never seen them. Campaigns draw from lists, so this is what gets them emailed.
Remove
Takes them off that one list. They stay in your contacts, and stay on any other list they're on.
Suppress
Blocks the address account-wide and takes them off every lead list. This is the one that sticks.

Adding is idempotent: someone already on the list is left alone rather than duplicated, so re-running a scan is safe.
