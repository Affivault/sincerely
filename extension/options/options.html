Sincerely extension

Connect the extension to your Sincerely account.

1. Where is your API?

Paste the host and we'll add /api/v1 for you. Use or .

2. API key

Create one in the app under Developer → API keys. It needs both read and write scopes. The key is shown only once, so copy it when you create it. It is stored on this machine only.

3. Preferences

How it works

  • Add puts someone on the campaign's lead list and enrols them. A contact is created first if your account has never seen them.
  • Remove ends that one sequence. They stay on the lead list, so a future import can re-enrol them.
  • Never contact again suppresses the address account-wide and pulls them out of every campaign still running. This is the one that sticks.
  • Someone already in another active campaign bound to a different lead list can't be added — the server blocks it and the extension shows you why.
